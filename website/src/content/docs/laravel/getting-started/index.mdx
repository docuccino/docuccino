Docuccino generates OpenAPI documentation from the real shape of your Laravel application. You
install one package; it reads your routes, controllers, form requests, resources, models, and
exception handling and produces an accurate document — with no annotations to start.

## Requirements

<CardGrid>
	<Card title="PHP 8.3+" icon="php" />
	<Card title="Laravel 12 or 13" icon="laravel" />
</CardGrid>

## Install

<Steps>

1. Require the package:

   ```bash
   composer require docuccino/laravel
   ```

2. Add Larastan, which powers type inference:

   ```bash
   composer require --dev larastan/larastan
   ```

   Docuccino's inference engine runs PHPStan with Larastan's model and container knowledge to read
   the real types in your code. PHPStan itself arrives with Docuccino; Larastan is the piece that
   teaches it Laravel.

3. Publish the config file — optional, but you'll want it soon:

   ```bash
   php artisan vendor:publish --tag=docuccino-config
   ```

   This writes `config/docuccino.php`. The package's defaults are already active without it, so
   publish when you want to change something. Out of the box they document every `api/*` route in
   your own application, export to `docs/openapi.json`, and serve an interactive viewer at
   `/docs/api`.

4. Export your first document:

   ```bash
   php artisan docuccino:export
   ```

   ```plaintext
   Wrote /home/you/invoices-api/docs/openapi.json (openapi-3.2).
   ```

</Steps>

That's it. Open `docs/openapi.json`, or visit `/docs/api` in your browser — the bundled viewer is
live in your `local` environment out of the box, and closed everywhere else until you name a gate.
[Your first export](/laravel/getting-started/first-export/) walks through what Docuccino read and
what it produced.

<Aside type="caution" title="Don't skip step 2">
If the engine can't boot — `larastan/larastan` missing being the usual reason — inference degrades to
off rather than failing the build. Routes, path parameters, validation rules, middleware-driven
security, attributes, and docblocks all keep working, but inferred response shapes, detected query
parameters, and automatic error responses go quiet. That keeps a CI export safe, at the cost of the
symptom being thin output rather than an error message.
</Aside>

## What gets added

<CardGrid>
	<Card title="Artisan commands" icon="seti:powershell">
		`docuccino:export`, `docuccino:validate`, `docuccino:diff`, `docuccino:cache`, and
		`docuccino:clear`. See the [commands reference](/laravel/reference/commands/).
	</Card>
	<Card title="A built-in viewer" icon="laptop">
		An interactive [Scalar](https://scalar.com) API reference at `/docs/api`, its spec at
		`/docs/api.json`, served from your own app — no external CDN required.
	</Card>
	<Card title="Automatic integrations" icon="puzzle">
		Support for form requests, API resources, Eloquent models, enums, Spatie Data, Spatie Query

	</Card>
	<Card title="Extension points" icon="setting">
		Register your own logic from any service provider with `Docuccino::extend()`. Every official
		integration is built with the same tools available to you.
	</Card>
</CardGrid>

## Where things live

<FileTree>

- config/
  - docuccino.php    the single config file — documents, routes, security, viewer
- docs/
  - openapi.json     your exported document (commit this)
- storage/
  - docuccino/       engine scratch files and the fragment cache (add to .gitignore)

</FileTree>

<Aside type="tip" title="Commit the output">
Docuccino's output is deterministic — identical code always produces byte-for-byte identical
output, with no timestamps, absolute paths, or shuffling. Commit `docs/openapi.json` and you get
clean, reviewable diffs on every change, plus the ability to gate CI with
[`docuccino:diff`](/laravel/reference/commands/#docuccinodiff).
</Aside>

## Turning it off

Set `DOCUCCINO_ENABLED=false` and Docuccino goes completely dormant: the viewer routes are never
registered and the artisan commands refuse to run. It's the switch to reach for on a production
host that has no business generating documentation.
